Upload your documents

Add any other documents that should go in the client's PDF package – for example project write-ups, payroll reports, contracts, invoices, time sheets or screenshots. The app does not read or change them: each file is added, as it is, after the last page of the study, in the order listed below. Use ↑ / ↓ to change the order.

Accepted: PDF, pictures (JPG, PNG – each picture becomes one page, fitted to the page) and text files (TXT). Word files are not accepted – open them in Word and use File → Save As → PDF, then upload the PDF. Several files can be chosen at once; up to 60 MB per upload. Password-protected PDFs cannot be added.
